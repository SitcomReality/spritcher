Spritcher Help Guide

1. Upload Image

Click the "Choose File" button or drag and drop an image file (PNG, JPG, GIF etc.) onto the page. The image will appear in the preview area.

Zoom/Pan: Use the + and - buttons or your mouse wheel to zoom in/out on the preview. Click and drag on the preview (while in Pan/Zoom mode) to move the image around.

2. Detection Settings

These settings control how Spritcher separates sprites from the background.

  • Background Removal Method:
    • Manual Threshold: Good for images with a uniform background color. Adjust the slider/number until the sprites are clearly white and the background is black in the "Show Thresholded" debug view. Lower values are more sensitive (more white).
    • Adaptive Threshold (Mean): Better for images with uneven lighting or gradients. It calculates the threshold locally for different parts of the image. Adjust 'Neighborhood Size' (odd numbers like 3, 5, 11...) and 'Sensitivity (C)' to fine-tune.
  • Minimum Sprite Size: Sets the minimum pixel area for a detected shape to be considered a sprite. Increase this to ignore small noise or unwanted artifacts.
  • Debugging Views & Overlays:
    • Show Grayscale: Displays the image converted to black and white.
    • Show Thresholded: Shows the black and white result of the background removal. This is crucial for tuning threshold settings. Sprites should be white, background black.
    • Show CCL IDs: Assigns a unique color to each distinct detected shape (blob). Useful for seeing how shapes are grouped.
    • Show Sprite Boxes: Draws blue boxes around the detected sprites. Enable this to use the editing tools.

Detect Sprites Button: Click this button (located at the bottom of the settings section) after adjusting settings. Spritcher will apply the processing steps and identify potential sprite boundaries based on your settings.

The found sprites will appear in the "Available Sprites" panel below, and blue boxes will appear on the image preview if "Show Sprite Boxes" is checked.

3. Sprite Editing Tools (Requires 'Show Sprite Boxes' enabled)

Use these tools to refine the automatically detected sprite boundaries.

  • Pan/Zoom: (Default mode) Click and drag to pan the image, use the mouse wheel or zoom buttons to zoom.
  • Select: Click on a blue sprite box in the preview to select it. Selected boxes turn brighter blue. Click empty space to deselect.
  • Edit Bounds: First, Select a sprite. Then switch to this mode. Drag the small green handles that appear on the selected box to resize its boundaries.
  • Add Box: Click and drag directly on the image preview to draw a new rectangular sprite box. Useful if a sprite wasn't detected automatically.
  • Delete Selected: First, Select a sprite. Then click this button to remove its box entirely. This removes it from detection results and any selection lists.

Note: Editing tools only affect sprites detected in the *currently* loaded image.

4. Manage Sprites for Sheet

This section lets you choose which detected sprites (potentially from multiple uploaded images) will be included in the final spritesheet.

  • Available Sprites: Shows previews of sprites detected in the most recently processed image.
    • Click a sprite preview here to add it to the 'Selected for Sheet' panel.
    • Sprites already selected are dimmed.
    • "Add All" adds all currently available sprites to the selection.
  • Selected for Sheet: Shows previews of all sprites you've chosen to include in the final spritesheet (can be from different source images).
    • Click a sprite preview here to remove it from the selection.
    • "Remove All" clears the entire selection.
    • The stats area shows size information about the selected sprites and helps determine layout settings.

5. Generate & Download Spritesheet

Configure the layout of your final spritesheet using the selected sprites.

  • Columns: How many sprites wide the sheet should be.
  • Sprite Padding: Empty space (in pixels) added inside each sprite's cell, around the sprite itself.
  • Cell Width / Cell Height: Defines the exact size of each grid cell.
    • Leave empty (or use "Use Recommended") to automatically size cells based on the largest selected sprite plus padding.
    • Enter specific values to force a uniform cell size. Sprites larger than the content area (Cell Size - Padding) will be scaled down to fit.
  • Horizontal/Vertical Align: How sprites are positioned within their cell's content area if they are smaller than the available space.

Click "Generate Spritesheet" to create the preview based on your selected sprites and layout settings. Once generated, click "Download Spritesheet" to save it as a PNG file.

Tips

  • Use the "Show Thresholded" view extensively to fine-tune the threshold settings – it's the most critical step for good detection.
  • If sprites are connected, try increasing the threshold value slightly (manual) or adjusting Adaptive settings.
  • If parts of sprites are missing, try decreasing the threshold value (manual).
  • Use the "Add Box" and "Edit Bounds" tools to manually fix detection errors.
  • You can upload multiple images, detect sprites in each, and add desired sprites from each image to the "Selected for Sheet" panel before generating the final combined spritesheet.
